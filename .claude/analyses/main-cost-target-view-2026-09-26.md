# Main session's view: the cost target at the pixel level (2026-09-26, 19:40 EDT)

Written before reading the Astra and Opus views, against `brief-cost-target-pixels-2026-09-26.md`.

**The three options**

1. **Decoded advantage, tuned decoder, scene-only, target = half the training maps' decoded advantage.** Per window: PSNR(decoded prediction, decoded true frame) minus PSNR(decoded copy-last latent, decoded true frame), both rendered by the decoder tuned on training-map frames, on rows 0 to 207 (no HUD). Per map: the mean paired difference over the 256 held-out windows, bootstrap over episodes. Target line: 0.5 × the same quantity averaged over the four training maps (today about 3.6 dB with the stock decoder, so the line sits near 1.8 dB; the tuned-decoder value comes Sunday). Cost: first budget whose curve reaches the line; right-censored if never within 4,000. In words: how many updates until the model's advantage over copying, as the viewer sees it, is half of what it has at home. Failure modes: the decoder is involved on both sides, so a decoder that renders blurred predictions kindly flatters the model (Opus showed the decoded copy is the harder reference, so the bias runs the other way); a tuned decoder that generalises worse to unseen arenas moves the line and the curve together, which is why the stock-decoder version is reported as the check. Compute: nothing beyond decoding both sides at each checkpoint, about 2 minutes per checkpoint.
2. **Fraction of the in-domain score recovered, raw pixels, tuned decoder, scene-only.** Per map: PSNR(decoded prediction, true frame) on the arena's held-out windows, expressed as the fraction of the gap closed between the arena's zero-shot score and the training maps' mean score: f(t) = (PSNR_t − PSNR_0) / (PSNR_home − PSNR_0). Target: f = 0.5. Cost: first budget with f ≥ 0.5. In words: how many updates to close half the gap to in-domain quality. This is Rohan's "how good can we get to in-domain data" made literal, and it is the most readable. Failure modes: absolute PSNR is dominated by how static the footage is (an arena whose footage is calmer than the training maps' can sit above PSNR_home at step 0 and get a negative gap), so the gap must be measured against persistence-matched footage or the arena's own ceiling; the reconstruction ceiling caps PSNR_t, so on static arenas the achievable fraction is below one and the line must be defined on the reachable range (ceiling minus zero-shot) rather than the home score. Compute: none beyond scoring.
3. **Fixed cut relative to copy-last, decoded, tuned decoder, scene-only (Astra's family).** Per map: the decoded advantage of option 1, target at a fixed absolute value, for example +1.5 dB (the model's error is 30 percent below copy-last's) chosen once from the zero-shot distribution so that no arena is above it at step 0. In words: how many updates until the model beats copying by a fixed margin as the viewer sees it. Failure modes: the margin is a choice with no in-domain anchor; a fixed margin means different fractions of the home advantage on different maps; if set low, several arenas have zero cost. Compute: none.

**Recommendation.** Headline: option 1, because it is pixel-level, uses the decoder Rohan wants involved, and is anchored to in-domain performance in the only way that survives static footage (an advantage over copying rather than an absolute score). Second panel: option 2 defined on the reachable range, because it is the plain-language claim ("half the gap to in-domain closed in N updates") and a reader will ask for it. Option 3 as a sensitivity line on the option-1 panel. Report every curve, the value at 4,000 updates and the area under the curve beside the crossing.

**On a latent number beside them.** Keep one, small: the decoder-free skill for the same checkpoints, in the appendix or as a thin line, because it is the only quantity that cannot be moved by a decoder choice and it is what protects the pixel result from the objection "you tuned the renderer". If Rohan wants it out of the main figure, it goes to the appendix; it should not vanish, because the full-fine-tune comparator and the LoRA curve can differ in latent space while looking alike through a forgiving decoder.
